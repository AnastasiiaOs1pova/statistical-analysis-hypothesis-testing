# Статистический анализ и проверка гипотез

Статистический анализ данных об округах США и отношении населения к вакцинации.

**Стек:** Python, pandas, NumPy, SciPy, Matplotlib, Seaborn.

## Данные

Датасет содержит **3035 наблюдений и 8 признаков**.

Основные признаки:
- `vaccine_hesitant` — доля населения, выражающего недоверие к вакцинации;
- `case_rate` — число случаев на 100 000 человек;
- `higher_edu` — показатель уровня образования;
- `median_age` — медианный возраст;
- `area_type` — тип округа (`Urban` / `Rural`).

## Задача

- исследовать распределения и выбросы;
- построить bootstrap-доверительные интервалы;
- проверить статистические гипотезы при сравнении групп;
- исследовать связи между признаками;
- реализовать часть статистических критериев вручную и сравнить результаты с `scipy`.

## Методы

- Shapiro–Wilk test;
- bootstrap и 95% confidence intervals;
- Central Limit Theorem;
- Kolmogorov–Smirnov test;
- Levene test;
- Welch t-test;
- Mann–Whitney U test;
- Pearson correlation;
- Spearman correlation.

Welch t-test, Mann–Whitney U, Pearson и Spearman дополнительно реализованы вручную.

## Результаты

- Для `vaccine_hesitant`, `case_rate`, `higher_edu` и `median_age` гипотеза о нормальности распределения была отвергнута.
- С помощью bootstrap построены 95% доверительные интервалы для среднего, медианы и стандартного отклонения.
- Для 60 непересекающихся выборок по 50 наблюдений распределение выборочных средних согласуется с нормальным распределением (`p = 0.652`).
- Между группами с высоким и низким уровнем `vaccine_hesitant` обнаружено статистически значимое различие `case_rate`: Welch t-test `t = -12.43`, `p ≈ 1.25e-34`.
- Распределение `vaccine_hesitant` статистически значимо различается между городскими и сельскими округами: Mann–Whitney `U = 553414`, `p ≈ 4.80e-108`.
- Между `higher_edu` и `vaccine_hesitant` обнаружена умеренная отрицательная связь:
  - Pearson: `r = -0.478`;
  - Spearman: `ρ = -0.477`.
- Результаты ручных реализаций статистических критериев совпали с результатами `scipy`.
